# 🚀 Animated Character Portfolio

An interactive and visually engaging personal portfolio website featuring a 3D animated character, smooth scrolling effects, and modern web design.

## 📌 About the Project

This project is an animated personal portfolio website developed using HTML, CSS, and JavaScript.

I created this project by following a video demonstration/tutorial from **Shreyansh Coding School** on YouTube. It was a hands-on learning experience that helped me understand website animations, interactive elements, scrolling behavior, and frontend development.

I also worked on understanding and improving the website's responsiveness and overall user experience.

## ✨ Features

- Interactive 3D character animation.
- Animated character that remains visible while scrolling.
- Smooth scrolling experience.
- Modern and attractive user interface.
- Responsive layout for different screen sizes.
- Interactive website sections.
- Custom styling and animation effects.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, transitions and animations.
- **JavaScript** – Interactive functionality and animation logic.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/saurabh-tiwari-1/animated-character-portfolio.git
   ```

2. Open the project folder in VS Code.

3. Install the Live Server extension if you haven't already.

4. Right-click `index.html`.

5. Select **Open with Live Server**.
